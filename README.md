# 산학협력 탐색그룹 · 2026 활동 기록

대한기계학회 기계인공지능연구회 산학협력 탐색그룹의 기업 방문 활동을 소개하는 밝은 톤의 단일 페이지 정적 사이트입니다. 별도 설치나 빌드 없이 `index.html`을 열면 볼 수 있습니다.

## 구성

- `index.html`: 활동 내용, 방문 날짜, 인원, 사진 설명
- `styles.css`: 반응형 화면과 인쇄 스타일
- `app.js`: 사진 넘기기, 사진 확대, 활동 위치 표시
- `contact-form.html`: 하단 기업 문의 입력 화면
- `contact-config.js`: 실제 Google 접수 창구의 연결 주소
- `contact.js`: 문의 화면 연결과 크기 조정
- `google-apps-script/`: 비공개 시트 저장·이메일 알림 코드와 연결 안내
- `assets/photos/`: 홈페이지용 WebP 사진 6장
- `.github/workflows/pages.yml`: GitHub Pages 배포 설정

사진을 누르면 확대해서 볼 수 있으며, 사진이 두 장인 방문 기록은 좌우 버튼으로 넘깁니다. 날짜 탐색과 모든 내용은 같은 페이지에 있습니다. 외부 폰트, 분석 도구, 외부 JavaScript 의존성이 없습니다. JavaScript를 꺼도 모든 활동 본문과 대표 사진은 표시됩니다.

## GitHub Pages에 게시

이 디렉터리의 사이트 파일을 GitHub 저장소 `main` 브랜치에 올린 뒤 Settings → Pages → Source를 GitHub Actions로 지정합니다. 제공된 워크플로는 `index.html`, `styles.css`, `app.js`, `contact-config.js`, `contact.js`, `contact-form.html`, `.nojekyll`, `assets/`만 사이트로 게시합니다. 사용자 또는 조직 페이지와 저장소별 하위 경로 모두 상대경로로 동작합니다. 공개 주소는 [https://sunwoong-yang.github.io/ksme-ai-industry/](https://sunwoong-yang.github.io/ksme-ai-industry/)이며, 소스 저장소는 [https://github.com/sunwoong-yang/ksme-ai-industry](https://github.com/sunwoong-yang/ksme-ai-industry)입니다. `main` 브랜치에 푸시하면 GitHub Actions에서 사이트를 배포합니다.

원본 발표자료·회의록 폴더와 ZIP은 `.gitignore`로 제외했습니다. 원본 자료는 홈페이지의 다운로드 항목으로 포함하지 않았습니다.

## 산학협력 문의·방문 신청

페이지 맨 아래에서 산학협력 문의와 방문회의·방문교육 신청을 함께 받습니다. 회사·기관명, 이름, 이메일, 전화번호, 문의·신청 내용은 필수이며 신청 유형은 복수 선택할 수 있습니다. 방문회의·방문교육·방문 세미나를 선택하면 희망 일정, 장소, 참석 대상·예상 인원을 입력할 수 있고, 방문교육에는 희망 교육 시간도 표시됩니다. 방문 상세 정보는 선택 항목이며, 일정은 담당자와 협의 후 확정합니다.

입력 내용은 기존 비공개 Google 스프레드시트에 누적되고, 지정한 담당자에게 메일로 알립니다. 방문 정보는 기존 열의 위치를 유지한 채 N:Q에 저장합니다. 메일 제목에서도 방문 신청 유형을 구분할 수 있습니다. 실제 연결 방법은 [Google 연결 안내](google-apps-script/SETUP.md)에 정리돼 있습니다.

2026년 10월 4일 Google 인증과 웹 앱 배포를 완료했습니다. 테스트 문의 한 건으로 접수번호 발급, 전화번호를 포함한 시트 저장, 알림 메일의 받은편지함 도착을 확인했습니다. 테스트 행은 `[연결 테스트]`로 구분했습니다. 홈페이지 본체는 [GitHub Pages](https://sunwoong-yang.github.io/ksme-ai-industry/)로 배포합니다.

2026년 10월 11일 기존 웹 앱을 버전 3으로 업데이트했습니다. 방문회의·방문교육을 함께 선택한 테스트 신청으로 접수 성공, 새 방문 정보 네 항목의 저장, 담당자 받은편지함에 상세 내용이 포함된 알림 도착을 확인했습니다. 기존 접수 기록은 유지했습니다.

문의 양식은 홈페이지에 삽입하며 새 창에서도 열 수 있습니다. 브라우저에서 삽입 화면이 12초 안에 준비되지 않으면 빈 영역 대신 문의 작성 버튼을 표시합니다. 작은 안내문을 포함한 사이트 텍스트는 최소 16px입니다.

배포 워크플로는 문의 화면 파일도 사이트에 포함합니다. 서버용 `google-apps-script/` 폴더는 홈페이지 배포 대상에서 제외합니다. 시트 ID와 알림 주소는 Google 스크립트 속성에 저장하며 공개 사이트 설정에 넣지 않습니다.

그룹의 목표와 운영진은 발표자료 8번 슬라이드에 근거합니다. 발표자료별 총 슬라이드 수는 서로 중복된 내용이 많으므로 활동 실적 지표로 사용하지 않았습니다. 5월 회의록의 발표 순서 개선 의견과 7월·9월 발표자료 2번 슬라이드의 목차를 대조해 운영 개선 내용을 반영했습니다.

LG전자 ES연구소와 양선웅 교수의 교류 시작은 7월 회의록에 기록돼 있습니다. 이를 공동연구 계약·과제 수주·기술개발 완료로 확대 해석하지 않았습니다. 자문단 필요성은 7월 회고, 후속 협의의 한계와 학술대회 부스·홈페이지·온라인 신청 창구 계획은 9월 회고에 근거합니다. 문의 창구는 사용자의 추가 요청으로 구현했으며, 실제 연결 상태에 따라 미리보기와 접수를 구분합니다.

9월 회의록의 방문 회사란에는 장소 성격의 `HD현대그룹글로벌R&D센터`가 적혀 있습니다. 발표자료의 표지 및 두 파일의 명칭을 함께 확인하여 기업명은 `HD현대사이트솔루션`, 장소는 `HD현대 글로벌 R&D Center`로 구분했습니다.

사진은 회의록에 포함된 실제 방문 사진에서 선별했습니다. 9월의 유사한 단체사진 중 한 장을 선택했습니다. 4월 단체사진은 내장 ImageGen으로 역광과 기울기를 보정한 파생본입니다. 그 외 사진은 원본 장면을 유지하면서 웹 전송용으로 인코딩했습니다. 얼굴과 현장 정보의 보존을 우선하며 원본 문서는 변경하지 않았습니다.

4월 사진 보정 프롬프트 요약: “실제 여섯 인물의 얼굴·표정·옷·자세·위치, 배경과 HD현대 표지판을 유지하고, 카메라 기울기와 어두운 인물 영역의 밝기만 절제하여 보정. 새 인물·사물·디테일 추가, 미화, 스타일 변환 금지.”

## 글꼴

본문·날짜·사진 설명·문의 입력은 KoPubWorld 돋움체 Medium, 제목·버튼은 Bold를 사용합니다. CSS의 400은 Medium 원본에, 700은 Bold 원본에 연결했습니다. 최소 글자 크기는 16px를 유지합니다.

현재는 방문자의 기기에 설치된 글꼴을 `local()`로 읽습니다. 글꼴 파일은 저장소에 포함하거나 서버에서 내려주지 않습니다. 미설치 기기에서는 맑은 고딕/Apple SD Gothic Neo/기본 sans-serif로 표시됩니다.

공개 사이트의 모든 방문자에게 동일하게 표시하려면 한국출판인회의의 웹서비스 임베딩 승인을 받은 뒤 웹폰트를 연결해야 합니다. [공식 사용 안내](https://www.kopus.org/biz-electronic-font2/)에서 서버 탑재·웹서비스 임베딩에 별도 승인이 필요하다고 명시합니다.

## 현대모비스 사진의 얼굴 가림

현대모비스 첫 번째 세미나 사진은 참석자의 얼굴 공개 제한 요청에 따라 내장 ImageGen으로 모든 보이는 얼굴을 강하게 블러 처리했습니다. 얼굴을 복원하거나 가림을 제거하지 않습니다. 두 번째 발표 사진은 변경하지 않았습니다. 본문 이미지와 확대 보기는 동일한 가림 처리 파일을 사용합니다. 원본 회의록과 작업용 추출 이미지는 공개 사이트에 포함하지 않습니다.

편집 지시: 첫 번째 현대모비스 세미나 사진의 작거나 가려진 얼굴·옆모습을 포함해 모든 보이는 얼굴을 충분히 강하고 부드러운 블러로 가립니다. 눈·코·입·안경 등 얼굴 특징이 확대해도 읽히지 않도록 하며, 얼굴 복원·교체 없이 촬영 구도와 현장 장면을 유지합니다.
